## Design Context

### Users
Mac users who use pi for general conversations and project-scoped work. They need to start fresh sessions quickly, select a model, and optionally bind Work sessions to a local project.

### Brand Personality
Native, calm, precise. The interface should feel like a focused macOS tool: approachable, quiet, and dependable during long-running agent work.

### Aesthetic Direction
Refined macOS minimalism based on the supplied references: soft neutral surfaces, restrained shadows, generous continuous corners, compact metadata controls, and clear black-and-white action states. Support both light and dark appearances through semantic colors.

### Design Principles

- Keep Chat and Work structurally consistent while exposing only mode-relevant choices.
- Make session state obvious: empty, ready to send, and executing must have distinct controls.
- Use progressive disclosure for project and model selection instead of permanent configuration panels.
- Prefer native SwiftUI/AppKit controls, keyboard behavior, accessibility labels, and system-adaptive appearance.
- Preserve a quiet content hierarchy; controls support the conversation rather than compete with it.
